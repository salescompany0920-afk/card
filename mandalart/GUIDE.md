이 문서는 `mandalart/index.html`(관리 페이지)의 설명서다. 페이지 주소: https://card.jungchongmoo.com/mandalart/

## 1. 만다라트의 역사와 발전 방향

**이름.** 불교의 만다라(曼荼羅, 중심에서 바깥으로 퍼지는 격자 도상) + 차트/아트. 일본에서 시작됐고, 일본에서는 "만다라 차트(マンダラチャート)"와 "만다라트(マンダラート)" 두 계보가 있다.

| 연도 | 사람 | 내용 |
|---|---|---|
| 1979 | 마쓰무라 야스오(松村寧雄), 클로버경영연구소 | 3×3 만다라 차트 고안. 경영·인생 계획용. "만다라 차트"는 이 연구소와 일반사단법인 만다라차트협회의 등록상표. |
| 1987 | 이마이즈미 히로아키(今泉浩晃), 디자이너 | 9×9 "만다라트(Mandal-Art)" 발상법 발표. 바인더 수첩 형태로 보급. |
| 2000년대 | 하라다 다카시(原田隆史) | 교사 출신 코치. 만다라트를 목표달성 시트("오픈 윈도우 64")로 정리해 "하라다 메소드"에 포함. 일본 학교·기업 연수에 널리 퍼짐. |
| 2010 | 오타니 쇼헤이, 하나마키히가시고 1학년 | 감독 사사키 히로시가 하라다 메소드를 배워 선수들에게 시트 작성을 시킴. 오타니의 시트가 2013년 이후 언론에 공개되며 세계적으로 유명해짐. |
| 2016~ | 앱·템플릿 시대 | 노션·옵시디언·캔바·미로 템플릿, 전용 앱(마만다 MyManda, 플랜빌더, Mandalart Habit Tracker 등). 습관 추적, 위젯, 사진 기록이 붙음. |
| 2024~ | AI 결합 | "목표 한 줄 → 64칸 자동 생성", OKR·KPI 트래커와 연결, 주간 리뷰 자동화. |

**발전 방향 요약.** ① 발상 도구(아이디어 확장) → ② 목표 분해 도구(오타니식) → ③ 습관 실행·추적 도구(앱) → ④ AI가 칸을 채우고 리뷰를 돕는 단계. 핵심은 "81칸을 채우는 것"에서 "64칸을 매일 행동으로 바꾸고 기록하는 것"으로 무게중심이 옮겨왔다는 점이다.

출처: [카오나비 — 마쓰무라 1987/상표](https://www.kaonavi.jp/dictionary/?p=15498), [일본어 위키백과 — 만다라트 1979/1987](https://ja.wikipedia.org/wiki/マンダラチャート), [라이프해커 JP — 오타니 시트](https://www.lifehacker.jp/article/2507-shohei-ohtani-goal-realization/), [Lucid — 하라다 메소드와의 관계](https://lucidspark.com/blog/mandala-chart). 고안자·연도는 자료마다 조금씩 다르므로 위 표는 가장 많이 인용되는 설을 따랐다.

## 2. 지금은 어떻게 쓰나 — 오타니와 사용자들의 방법

### 오타니 시트의 구조(규칙)

```
┌───────┬───────┬───────┐
│ 체력   │ 제구   │ 구위   │   바깥 8블록: 각 블록 가운데 = 테마,
├───────┼───────┼───────┤   둘레 8칸 = 그 테마의 행동 키워드
│ 멘탈   │★8구단 │ 구속   │   ★ 가운데: 핵심 목표 1개 (기한·측정 가능)
│       │드래프트1│160km  │
├───────┼───────┼───────┤
│ 인간성 │  운   │ 변화구 │
└───────┴───────┴───────┘
```

- 가운데 한 칸: **"8구단 드래프트 1순위"** — 달성했는지 바로 알 수 있는 한 줄.
- 둘레 8칸: 체력 만들기, 제구, 구위(킬레), 구속 160km/h, 변화구, 운, 인간성, 멘탈. 기술 4 + 몸 1 + 마음·태도 3.
- 바깥 64칸: 대부분 **동사형 행동**. 예) 운 → 쓰레기 줍기, 방 청소, 심판을 대하는 태도, 인사, 책 읽기. 체력 → 저녁 밥 7공기·아침 3공기, 웨이트 수치 목표. 멘탈 → 일희일비하지 않기, 동료를 생각하는 마음.
- 포인트 세 가지: ① 목표가 **측정 가능**했다 ② "운"처럼 통제 안 되는 것도 **통제 가능한 행동**으로 바꿨다 ③ 64칸 중 절반 이상이 **오늘 당장 할 수 있는 작은 일**이었다.

### 요즘 사용자들의 방식

1. **연 1장 + 분기 리뷰.** 연초에 9×9를 쓰고, 분기마다 칸을 지우고 바꾼다. 처음 쓴 칸의 30~40%는 바뀌는 게 정상.
2. **칸 ≠ 할 일.** 칸에는 키워드만, 실제 할 일(언제·몇 번·얼마나)은 별도 체크리스트·앱에 둔다. 칸은 "지도", 체크리스트는 "오늘의 경로".
3. **습관 트래커 연결.** 64칸 중 매일 할 것 5~10개만 골라 체크한다. 64개를 전부 매일 하려 하면 2주 만에 무너진다.
4. **주간 리뷰 3줄.** 잘한 것 / 막힌 것 / 다음 주 바꿀 한 가지. 안 되는 칸은 더 잘게 쪼개거나 버린다.
5. **팀·가족용.** 가운데를 팀 목표로 놓고 8칸을 구성원이 하나씩 맡는 변형도 흔하다.

## 3. 내 만다라트 개선점과 실천 연결

### 원본(v1)에서 보이는 것

| 항목 | 지금 상태 | 왜 문제인가 | 개선 |
|---|---|---|---|
| 가운데 칸 | "정신" | 가운데는 **목표**여야 한다. 테마가 들어가면 8테마가 무엇을 위해 있는지 사라진다. | 가운데에 기한 있는 핵심 목표 한 줄. 정신은 테마로 이동. |
| 테마 수 | 9개(민주·민민·관계·건강·정신·경제·AI·골프·인간) | 가운데 블록은 목표 1 + 테마 8. 9개면 한 칸이 넘친다. | "정신"과 "인간"을 **"정신·배움"**으로 합침(둘 다 내면·공부 영역). |
| 블록 가운데 | 블록마다 9개 항목이 꽉 참 | 각 블록 가운데는 테마 이름 자리. 그래야 9×9가 한눈에 읽힌다. | 블록당 8칸으로 정리. 넘친 1칸은 비슷한 칸과 합치고 원본 내용은 메모에 보존. |
| 칸 내용 | 명사 위주("수면", "그립") + 일부 문장 | 명사는 방향, 문장은 행동. 섞이면 뭘 체크할지 모른다. | 칸은 명사 키워드로 통일, 행동은 **실천 항목**(페이지에서 칸 클릭)에 주기와 함께. |
| 골프 메모 | "모든 챕터마다 발·무릎·…·손가락 체크" | 좋은 통찰인데 칸 밖에 떠 있다. | 각 스윙 칸의 실천 항목에 "체크: 부위"로 넣고, 테마 메모에 원문 보존. |
| 중복 | AI 블록에 신발·골프·메디쏠라·민주·가족 | 다른 테마와 겹침. | "AI × 신발"처럼 **적용 대상**임을 이름에 드러냄. 겹침이 아니라 교차점으로 정의. |
| 오타 | 깜작→깜짝, 리더쉽→리더십, 다운스윈→다운스윙, 임펙트→임팩트, 메니져→매니저 | — | 수정. "불간거리"는 "볼 간 거리(스탠스)"로 추정해 적음. 아니면 페이지에서 바로 고치면 됨. |

### "원래 적고 구체적인 것들은 따로 적는 거야?" → 그렇다

- **9×9 칸** = 키워드 지도. 한 칸에 2~6글자. 1년에 몇 번만 바뀐다.
- **실천 항목** = 칸 하나당 1~3개. "언제 · 몇 번 · 얼마나"가 들어간 문장. 주기(매일/매주/매월/1회)를 붙인다. 자주 바뀐다.
- **오늘 체크** = 실천 항목 중 오늘 주기에 해당하는 것만 모아 체크. 연속 일수가 쌓인다.
- **주간 리뷰** = 테마별 실천률을 보고 3줄을 쓴다.

오타니도 64칸에 "쓰레기 줍기" 같은 행동을 적었지만, 실제 하루 식사량·웨이트 수치는 시트 밖 트레이닝 노트에 따로 적었다. 칸은 짧게, 기록은 따로.

합친 칸에는 페이지의 "메모"란에 "원본: …"을 남겨 두었다. 마음에 안 들면 칸을 눌러 바로 바꾸면 된다.

### 바로 할 일 (첫 주)

1. 페이지를 열고 **가운데 칸(핵심 목표)**을 적는다. 비어 있으면 나머지는 방향을 잃는다. 예) "2027년 12월까지 ○○ 매출 ○억 + 체지방 ○%" 처럼 숫자·날짜가 들어가게.
2. 미리 넣어 둔 실천 항목(예시)은 **내 말로 고치거나 지운다.** 매일 항목은 **5~8개**만 남긴다.
3. 7일간 "오늘 실천" 탭만 쓴다. 칸은 건드리지 않는다.
4. 일요일에 "주간 리뷰" 3줄. 실천률 0%인 테마가 있으면 그 테마의 실천 항목을 더 작게 만든다("30분 운동" → "운동복 갈아입기").
5. 한 달 뒤 칸 자체를 손본다. 한 번도 안 건드린 칸은 "버릴 것" 후보.

## 4. 관리 페이지 사용법 (`mandalart/index.html`)

- **만다라트 탭**: 9×9 전체 또는 블록 보기(휴대폰). 칸 클릭 → 오른쪽 편집창(제목·상태·실천 항목·메모). 테마 칸 클릭 → 테마 이름·메모와 8칸 목록.
- **오늘 실천 탭**: 매일/이번 주/이번 달/1회 항목을 체크. 매일 항목은 연속 일수(🔥) 표시.
- **주간 리뷰 탭**: 테마별 실천률 바 + 3줄 리뷰 저장(이력 누적).
- **JSON 백업 / 가져오기**: 데이터는 브라우저(localStorage)에만 저장된다. 기기 변경·브라우저 초기화에 대비해 가끔 백업. 백업 파일은 다른 기기에서 가져오기로 복원.
- **인쇄**: A4 가로, 9×9만 출력. 벽에 붙이는 용도.
- **템플릿으로 초기화**: 위 v2 개선안으로 되돌림(되돌릴 수 없으니 백업 먼저).
- 데이터는 서버로 가지 않는다. 페이지는 정적 HTML 한 파일이라 GitHub Pages 그대로 올라간다.

## 5. 새 "공간"을 따로 만들고 싶을 때

지금은 `card` 저장소 안 `mandalart/` 폴더에 두었다(명함과 섞이지 않음, 같은 도메인의 `/mandalart/` 주소). 완전히 분리하고 싶으면:

1. **GitHub 저장소 새로 만들기**: github.com → 오른쪽 위 "+" → New repository → 이름(예: `mandalart`) → Public → Create. `mandalart/` 폴더 내용을 그 저장소 루트에 올리고 Settings → Pages에서 배포하면 `salescompany0920-afk.github.io/mandalart`로 열린다.
2. **Claude Code(클라우드)에서 그 저장소 쓰기**: claude.ai/code → 새 세션 → 저장소 선택에서 새 저장소 선택. 목록에 없으면 https://claude.ai/connect-github 에서 GitHub 연결을 갱신하고, Claude GitHub 앱에 새 저장소 접근을 허용한다. 세션의 저장소는 시작할 때 정해지므로 새 세션을 열어야 한다.
3. **환경(기본값)**: "기본값"은 클라우드 환경 이름이다. 저장소를 바꾸는 데는 환경을 새로 만들 필요가 없다. 네트워크 정책이나 설치 도구를 바꾸고 싶을 때만 claude.ai/code → 환경 설정에서 새 환경을 만든다.
